# Fishing is All You Need

一款以 **2D 像素风 + 治愈氛围 + 轻松钓鱼循环** 为核心的休闲钓鱼游戏原型项目。

当前仓库是一个基于 **Godot 4.7** 的早期工程，需求主要来自 [`Fishing is All You Need - PRD.md`](./Fishing%20is%20All%20You%20Need%20-%20PRD.md)。本 README 根据当前目录中的 PRD 整理，便于后续开发、协作与项目初始化。

## 项目定位

玩家将扮演一位中世纪青年，带着猫咪伙伴，在宁静湖面上的木筏中进行钓鱼。游戏强调：

- 治愈、放松的情绪体验
- 简单但有反馈感的钓鱼循环
- 像素风画面与温暖配色
- 鱼种收集、图鉴解锁与轻度成长

## 目标用户

- 喜欢像素风、治愈系画面的休闲玩家
- 喜欢《Stardew Valley》《Terraria》《Minecraft》钓鱼玩法的玩家
- 希望在碎片时间内放松解压的用户

## 核心玩法循环

游戏的基础循环如下：

> 抛竿 → 等待上钩 → 咬钩提示 → 搏斗小游戏 → 成功/失败 → 结果展示 → 再次抛竿

### 1. 抛竿（Cast）

- 默认按键：`Space`
- 表现：鱼线抛物线飞出、浮标落水、水花与波纹反馈
- 状态切换：进入等待上钩状态

### 2. 等待上钩（Waiting）

- 基础上钩率：每秒约 `20%`
- 预期等待时间：`3~5 秒`
- 提示反馈：
  - 浮标突然下沉
  - 水花动画
  - 音效提示
  - UI 感叹号提示

### 3. 搏斗小游戏（Battle）

PRD 设计了两种随机触发的玩法，各占 `50%`：

#### 方案 A：进度条追踪

- 参考《Stardew Valley》
- 玩家控制绿色区域上下移动
- 鱼图标随机运动
- 覆盖鱼图标时捕获进度上涨，否则下降
- 进度条填满即成功，清空即失败

#### 方案 B：QTE 判定

- 参考节奏/QTE 式判定
- 指针沿圆盘顺时针旋转
- 在绿色区间按下 `Space` 视为成功
- 在白色完美区间按下可获得更高收益
- 多次成功后钓鱼成功，连续失误则鱼逃走

### 4. 结果展示（Result）

成功时展示结果卡片，包括：

- 鱼的像素图鉴
- 中英文名称
- 分类信息
- 重量
- 金币价值
- 是否首次发现（`NEW!`）
- 趣味描述

失败时显示鱼的剪影与 “It got away...” 文案，保留未知感与再次尝试的动机。

## 美术与氛围方向

### 视觉风格

- **2D 像素风**
- **温暖治愈色调**
- 参考作品：**Cast n' Chill**

### 画面构图

- 平视湖面视角
- 天空占主要画面空间，湖面位于下方
- 木筏居中偏左
- 主角与猫咪是主要视觉焦点

### 技术规格（PRD 目标）

- 基准分辨率：`320 × 180`
- 输出分辨率：`1920 × 1080`（整数倍缩放）
- 角色动画帧率：`8~12 fps`
- 目标帧率：`60 fps`

## 鱼种系统

游戏计划提供鱼种图鉴与稀有度体系，初版目标为 **30~50 种鱼**。

### 稀有度分层

| 稀有度 | 出现概率 | 难度 | 价值范围 |
| --- | --- | --- | --- |
| 普通 | 50% | 简单 | 5~20 金币 |
| 稀有 | 30% | 中等 | 30~80 金币 |
| 史诗 | 15% | 困难 | 100~300 金币 |
| 传说 | 5% | 极难 | 500~2000 金币 |

### 图鉴内容

每种鱼计划包含：

- 像素立绘/图鉴图
- 名称
- 分类信息
- 体重范围
- 趣味描述
- 首次钓到时间

## 世界观与剧情基调

故事背景设定在一个带有中世纪氛围的小镇。主角厌倦教条生活，在梦中受到“金色之鱼”的启示后，带着猫咪乘木筏出航，通过钓鱼逐步拼凑关于世界真理的碎片。

该设定服务于两件事：

- 给“日复一日钓鱼”一个轻叙事动机
- 为后续传说鱼、剧情碎片、CG 过场留出扩展空间

## UI / UX 规划

主 HUD 预计包括：

- 左上角：金币数量
- 左上角下方：图鉴进度
- 右上角：时间 / 天气
- 底部居中：操作提示
- 右上角：暂停 / 设置按钮

主要交互流程：

1. 主菜单
2. 进入游戏主画面
3. 完成钓鱼循环
4. 查看图鉴
5. 打开设置

## 快速开始

### 环境要求

- Godot `4.7`
- Git

1. 使用 Godot 4.7 打开当前仓库目录
